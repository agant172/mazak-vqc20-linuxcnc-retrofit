# Wiring-Diagram Find List — "Proposed Cross-Walk" Signals

**Date:** 2026-08-08 · **Machine:** VQC-20/40 SN 060231
**Purpose:** locate each signal stuck in *proposed / commissioning-pending* in its
physical wiring so it can be traced and landed. Triangulated across three layers:
PLC element list (address/symbol), OEM schematic page in `41434WB.pdf`, and the
BBIA1 terminal-unit wire number (the reused machine-side interface).

> Page numbers are PDF pages in `41434WB.pdf` = `manuals/41434WB <page>.pdf`.
> **This is a research/trace aid, not authority.** `mesa/current_pin_authority.csv`
> remains the wiring authority.

## Owner resolutions (2026-08-08) applied here
1. **MANUAL_TOOL_UNCLAMP_PB = foot switch** (not head). Confirmed by mnemonic
   `TUCFS` = Tool UnClamp **F**oot **S**witch.
2. **PRS-13 = tool-number bit**, NOT magazine in-position. `MAG_IN_POS` (X00D
   MIPRS) is a *separate* prox and must be located on its own — do not tie it to
   PRS-13. (Open: is PRS-13 a 6th tool-ID bit beyond PRS-21..25? flag for BCD map.)
3. **HYD_PUMP_ON** second load = **head-lube pump** (element list), even though
   the SSR-board column label reads "heat-exchanger". Use head-lube.
4. **SPINDLE_ORIENT_LOGEAR / CTL = low-gear orient assist** (authority is right);
   the BBIA1 "orient loop check" label is the mislabel.
