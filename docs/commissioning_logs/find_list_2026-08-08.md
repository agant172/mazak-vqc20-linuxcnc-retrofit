## Owner resolutions (2026-08-08) applied here
1. **MANUAL_TOOL_UNCLAMP_PB = foot switch** (not head). Confirmed by mnemonic
   `TUCFS` = Tool UnClamp **F**oot **S**witch.
2. ~~PRS-13 = tool-number bit~~ **SUPERSEDED by diagram (pg 135):** PRS-13 =
   MIPRS = **MAGAZINE INPOSITION** (wire 213, X0D). The tool-number bits are
   **PRS-21…25** ("MAGAZINE POSITION 1/2/4/8/10" = 711P/712P/714P/718P/721P).
   MIPRS is the in-position strobe that validates those BCD bits — matches the
   CSV note "BCD pot number valid only while TRUE". So `MAG_IN_POS = PRS-13`
   (original mapping) is correct. Owner confirmed: trust the diagram (2026-08-08).
3. **HYD_PUMP_ON** second load = **head-lube pump** (element list), even though
   the SSR-board column label reads "heat-exchanger". Use head-lube.
4. **SPINDLE_ORIENT_LOGEAR / CTL = low-gear orient assist** (authority is right);
   the BBIA1 "orient loop check" label is the mislabel.
