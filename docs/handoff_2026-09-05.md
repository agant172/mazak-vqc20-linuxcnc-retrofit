## Behaviour changes a future reader must know

- **Gear coils are energised at rest and before the arm.** `state` reads 3,
  not 0, whenever the machine is idle in a gear; the default-low coil is
  commanded from the first scan (no hydraulic pressure yet — harmless, same as
  OEM LSR). Not a bug. Only the handoff sequence and AL47 drop a coil now.
- **Thermal / door / lube stop nothing.** They light LEDs in AXIS. The
  hardwired door lock and motor thermal protection remain OEM. Upgrading any
  one to an interlock is a one-net change into the existing
  `spindle-permit-and` / `watchdog-fault-or` stages.
- **LED sense** is green on input TRUE. Polarity is unverified on all three
  inputs; fix an inverted chain with `-not` on the net, never by recolouring.
