# BBIA-1 CN1–CN6 & CN11 Wire Data — Source for the Laminated Reference Sheet

Companion CSV: [`bbia1_cn_labels_epson.csv`](bbia1_cn_labels_epson.csv) — 164
rows, one per active pin across CN1, CN2, CN3, CN4, CN5, CN6, and CN11.

## Purpose (revised 2026-08-09)

This CSV is the **data source for the laminated cabinet reference sheet**, not
a label-printer batch. The deliverable is:

1. `python3 scripts/generate_wire_reference_sheet.py` — regenerates
   [`bbia1_wire_reference_sheet.html`](bbia1_wire_reference_sheet.html) from
   this CSV plus the Mesa-end ferrule crosswalk.
2. Open the HTML in a browser, print on 8.5"×11", laminate, hang in the
   cabinet door with the schematics.
3. Regenerate and reprint after any label CSV change — the sheet's header
   carries the generation date and repo commit so a stale printed copy is
   detectable at a glance.

**The per-wire Epson ferrule workflow for this batch is retired.** The factory
jacket print a few inches back from each cut identifies every conductor, and
the laminated sheet does the lookup. (The former Epson Label Editor import
instructions are in git history if ever needed. The
[`bbia1_mesa_end_ferrules_epson.csv`](bbia1_mesa_end_ferrules_epson.csv) batch
is unaffected — those destination ferrules remain per-wire, per
[its instructions](bbia1_mesa_end_ferrules_epson.md).)

If an individual conductor's jacket print turns out unreadable at the cut,
label that one wire ad hoc (hand-typed in Label Editor from this CSV's row);
there is no maintained bulk batch for that case.

## CSV schema

| Column | Contents | Notes |
|--------|----------|-------|
| **Wire** | Factory wire number from the Mazak jacket print (e.g. `232`, `EHB`, `*DECZ`, `0G`, `+24V`) | Primary identifier; matches the print visible on the intact sheath. |
| **Location** | Connector and pin on the BBIA-1 (e.g. `CN2-15`, `CN6-39`) | The key used against [`bbia1_cn_pinouts.md`](../bbia1_cn_pinouts.md) and the retrofit crosswalk. |
| **Signal** | Mnemonic / functional name (e.g. `X-AXIS ZERO RETURN DEC`, `EMG STOP`) | Human-readable, for troubleshooting. |

The file is generated by `scripts/generate_label_csvs.py` — do not hand-edit;
the CI authority gate rejects drift from the generator.
